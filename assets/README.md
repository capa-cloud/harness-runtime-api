The lifecycle SVGs are generated by `node scripts/generate-lifecycle.mjs`. Use `--check` to verify
reproducibility without writing files. On 2026-10-09, both languages were inspected in Chrome at
1600 x 900 and 1024 x 576: nine states, twelve transitions, readable labels, and no visible overlap.
Failure paths cover running and both human-wait states; the normative runtime model remains the
source of truth. Regression tests check these paths and generator synchronization.
